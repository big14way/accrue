# Accrue — progress update, 26 Sep 2026

**Accrue is an ERC-8183 job escrow on Monad that earns while it waits, pays only on verified delivery, and lets the provider borrow against the job.** Live console: https://accrue-virid.vercel.app · Code: https://github.com/big14way/accrue

## What we shipped

**Settling in Agora AUSD.** The full stack is redeployed on Monad testnet with AUSD as the settlement asset (block 64964439), all 11 contracts verified on Sourcify. Testnet AUSD comes from Agora's faucet. The first deployment stays live for its drill history.

**The evaluator is a contract, and Chainlink proved it.** A Chainlink CRE workflow re-fetched a deliverable inside the DON, reached consensus on the body and settled job #20 through the Monad Keystone forwarder. A threshold committee is the fallback. A verdict for any hash other than the one the provider submitted is refused on chain.

**Credit priced from ERC-8004.** Advance limit, per-block rate and bond come from a pure view over the provider's on-chain reputation. Our provider is agent #1891; the registry on Monad testnet has issued more than 1,900 ids, so the credit file already has a population.

**Envio Cloud in production.** Every history view in the console (timelines, liens, refusals, pool activity) is served by Envio HyperIndex hosted on Envio Cloud, synced over HyperSync.

**We attacked it before you could.** Six drills plus a live agent run and the CRE settlement, all committed with transaction links:
- D1 stale data refused in the provider's own transaction; missed deadline refunded with yield in one call
- D2 one transaction pays pool, provider (principal + yield bonus), client and protocol, and writes ERC-8004
- D3 advance taken, bad delivery rejected: bond seized, shortfall recorded, credit limit 10 % → 0 %
- D4 wrong-hash, non-member and non-forwarder attestations all refused
- D5 20 jobs funded and settled back to back: 141 transactions, 1,349 blocks, about 0.2 MON per job lifecycle
- D6 a Claude agent holding the provider key tried every way to get paid without delivering; every path was refused, its advance ended as a recorded default, limit 55 % → 40 %

99 Foundry tests including fuzz and invariants. 48 jobs settled across the two testnet deployments, every step re-runnable.

**Console and story.** New landing page, a four-minute pitch and demo video, and a written submission covering who it is for (agents selling verifiable data and API work, and the marketplaces that host them), the gap, and the revenue model (a protocol share of realised yield, advance interest, then a spread and origination fee on mainnet).
